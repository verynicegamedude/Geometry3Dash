# Geometry3Dash (UE4)

3D fan remake of Geometry Dash built in Unreal Engine 4.

## Features
- Full 3D platformer with third-person camera (free rotation)
- Core mechanics: jump, boost jump, obstacles, checkpoints, respawn, attempt counter
- Vertical level design — levels extend upward, not just horizontally
- All original gameplay mechanics (excluding character model switching)

## What I learned / design decisions
## Design decisions
The main challenge was preserving the feel of the original — tight controls,
precise jumps, rhythm-driven obstacles — while opening up a third spatial axis.
Vertical level progression was added to increase variety without breaking
the core loop. Checkpoint and respawn systems were designed to keep frustration
low while maintaining the "one more attempt" loop that makes the original addictive.
